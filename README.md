<h1 align="center">Тихий сад</h1>
<p align="center"><em>Маленькие шаги. Большой рост.</em></p>

Уютный дашборд для планирования дня и заботы о себе. Выполняй дела, выращивай цветы и находи время для небольших пауз.

**Автор:** Агеечкина Ксения
**Группа:** 4-МД-15

---

## 🌱 Как это работает

На главной странице можно добавлять, удалять и переставлять виджеты. В разделе «Мой сад» — выбирать растение и открывать новые цветы за выполненные задания. Каждые **5 завершённых дел** приносят один цветок; листья появляются по мере прогресса.

Задачи, раскладка и профиль сохраняются в браузере. Сайт адаптируется под компьютер, планшет и телефон.

## 🪴 Виджеты

| Виджет | Что умеет |
| --- | --- |
| **Живой сад** | Растение растёт вместе с прогрессом, оформление сада зависит от погоды. |
| **План дня** | Добавление, удаление и выполнение задач, фильтры и просмотр полного списка. |
| **Погода** | Выбор города, температура, влажность, ветер и обновление прогноза. |
| **Прогресс дня** | Диаграмма выполненных дел и счётчик задач. |
| **Ритм недели** | Статистика завершённых дел за последние семь дней. |
| **Мои цветы** | Количество выращенных цветов. |
| **Тихий фокус** | Таймер на 25 минут с запуском и паузой. |
| **Стакан воды** | Учёт выпитых стаканов — до 10 в день. |
| **Пауза дыхания** | Анимация вдоха и выдоха для короткого отдыха. |
| **Живой мир** | Фотография и название растения, кнопка обновления. |
| **Курсы валют** | USD, EUR и CNY, пересчёт в рубли и обновление курсов. |
| **Цитата дня** | Случайная фраза, которая меняется по кнопке «Обновить». |

## ☁️ Данные

Прогноз приходит из **MET Norway**, растения — из **iNaturalist**, курсы валют — из **cbr-xml-daily.ru**. Для загрузки нужен интернет; при недоступности сервиса виджет показывает сообщение об ошибке.
